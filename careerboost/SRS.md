# CareerBoost — Software Requirements Specification (SRS)

**Нұсқа:** 1.0  
**Жоба түрі:** Java консольдік прототип  
**Мақсаты:** жұмыс іздеушіге профиль құруға, түйіндемені тексеруге және вакансияларды іздеу/сұрыптауға көмектесу.

## 1. Жоба сипаттамасы

CareerBoost — жұмыс іздеушілер мен рекрутерлерге арналған мансап платформасының прототипі. MVP-де жүйе консоль арқылы жұмыс істейді және негізгі бизнес логиканы көрсетеді. Деректер демонстрациялық түрде жадта сақталады.

## 2. Мүдделі тараптар және пайдаланушылар

- **Жұмыс іздеуші (Candidate):** профиль толтырады, түйіндемесін тексереді, вакансия қарайды.
- **Рекрутер (Recruiter):** вакансия жариялау интерфейсін пайдаланады.
- **Жоба әкімшісі:** талаптар мен шығарылымдарды бақылайды.

## 3. Функционалдық талаптар (FR)

| ID | Талап |
|---|---|

| FR-06 | Тексеру нәтижесінде қателер мен ұсыныстар көрсетілуі керек. |

## 4. Функционалдық емес талаптар (NFR)

- **NFR-01 Қолдану жеңілдігі:** мәзір мен хабарламалар түсінікті қазақ тілінде болуы керек.
- **NFR-02 Өнімділік:** демонстрациялық деректерде әр операция 2 секундтан аз уақытта орындалуы керек.
- **NFR-03 Үйлесімділік:** Java 17 немесе одан жоғары нұсқада жұмыс істеуі керек.
- **NFR-04 Тасымалдану:** Windows, Linux және macOS жүйелерінде стандартты JDK арқылы іске қосылуы керек.
- **NFR-05 Қолдауға ыңғайлылық:** паттерндер жеке кластарға/интерфейстерге бөлініп, атаулары түсінікті болуы керек.
- **NFR-06 Сенімділік:** қате енгізілген мәзір таңдауы бағдарламаны бірден тоқтатпауы керек.
- **NFR-07 Қауіпсіздік:** прототип нақты парольдерді немесе төлем картасының деректерін сұрамауы керек.
- **NFR-08 Кеңейтілу:** жаңа сұрыптау стратегиясын немесе пайдаланушы рөлін қолданыстағы кодты аз өзгертіп қосуға болатындай құрылуы керек.

## 5. User Stories және қабылдау критерийлері

### US-01 — Профиль құру
**Мен жұмыс іздеуші ретінде** өз профилімді құрып, ақпараттарымды бір жерде сақтағым келеді.

Қабылдау критерийлері:
- Берілген ат пен email профильге жазылады.
- Дағдылар мен тәжірибе қосымша берілуі мүмкін.
- Құрылған профиль консольде көрсетіледі.

### US-02 — Профильді кезең-кезеңімен толтыру
**Мен пайдаланушы ретінде** профильді Builder арқылы біртіндеп жасағым келеді.

Қабылдау критерийлері:
- Builder міндетті өрістерді қабылдайды.
- Қосымша өрістерді тізбектей қосуға болады.
- Соңында бір Profile объектісі қайтарылады.

### US-03 — Рөлді таңдау
**Мен пайдаланушы ретінде** Candidate немесе Recruiter рөлін таңдағым келеді.

Қабылдау критерийлері:
- Екі рөлге бөлек компоненттер жиыны беріледі.
- Бір фабрика бір-бірімен үйлесімді компоненттерді жасайды.
- Таңдалған рөл консольге шығады.

### US-04 — Түйіндемені тексеру
**Мен кандидат ретінде** түйіндемемнің толықтығын тексергім келеді.

Қабылдау критерийлері:
- Тексеру ортақ шаблон бойынша орындалады.
- Аты, email және дағды бос болса, ескерту беріледі.
- Тексеру соңында қорытынды көрсетіледі.

### US-05 — Тексеру процесінің ретін сақтау
**Мен жүйе әзірлеушісі ретінде** тексеру қадамдарының ретін өзгертпей, ішкі қадамдарды кеңейткім келеді.

Қабылдау критерийлері:
- Негізгі алгоритм Template Method ішінде анықталған.
- Қадамдар белгіленген ретпен орындалады.
- Нақты тексеру логикасын мұрагер класс береді.

### US-06 — Вакансияларды жалақы бойынша сұрыптау
**Мен кандидат ретінде** ең жоғары жалақысы бар вакансияларды бірінші көргім келеді.

Қабылдау критерийлері:
- Salary Strategy жалақыны кему ретімен сұрыптайды.
- Бастапқы тізім өзгеріссіз қалуы мүмкін.
- Нәтиже консольде көрсетіледі.

### US-07 — Вакансияларды атауы бойынша сұрыптау
**Мен кандидат ретінде** вакансияларды атауы бойынша табуды қалаймын.

Қабылдау критерийлері:
- Title Strategy атауларды алфавит бойынша сұрыптайды.
- Бос тізім қатесіз өңделеді.
- Нәтиже түсінікті форматта көрсетіледі.

### US-08 — Сыртқы вакансияны импорттау
**Мен рекрутер ретінде** сыртқы жүйеден келген вакансияны CareerBoost форматына ауыстырғым келеді.

Қабылдау критерийлері:
- Ескі форматтағы дерек қабылданады.
- Adapter ішкі Vacancy объектісін қайтарады.
- Лауазым, компания және жалақы дұрыс көшіріледі.

### US-09 — Дерек форматын бейімдеу
**Мен жүйе әзірлеушісі ретінде** сыртқы API форматын негізгі модельді өзгертпей қолдағым келеді.

Қабылдау критерийлері:
- Сыртқы класс ішкі интерфейске тікелей тәуелді болмайды.
- Түрлендіру Adapter арқылы жасалады.
- Негізгі Vacancy моделі сыртқы форматты білмейді.

### US-10 — Профильге талдау жасау
**Мен кандидат ретінде** профилім бойынша қысқаша есеп алғым келеді.

Қабылдау критерийлері:
- Visitor профиль объектісін қабылдайды.
- Дағдылар саны есептеледі.
- Есеп консольге шығарылады.

### US-11 — Вакансияға талдау жасау
**Мен рекрутер ретінде** вакансия деректеріне есеп жасатқым келеді.

Қабылдау критерийлері:
- Visitor Vacancy объектісіне кіре алады.
- Вакансия атауы мен жалақысы есепке алынады.
- Нәтиже негізгі модель кластарын өзгертпей шығарылады.

### US-12 — Демонстрацияны іске қосу
**Мен оқытушы/пайдаланушы ретінде** 6 паттерннің қалай жұмыс істейтінін көргім келеді.

Қабылдау критерийлері:
- Бағдарлама Java терминалында іске қосылады.
- Әр паттерннің атауы мен мақсаты көрсетіледі.
- Әр паттерн үшін нақты орындалу нәтижесі шығады.

## 6. MVP шекарасы

### MVP құрамына кіреді
- Консольдік мәзір және қазақша түсіндірме.
- Профильді Builder арқылы құру.
- Abstract Factory арқылы Candidate/Recruiter UI компоненттерін жасау.
- Template Method арқылы түйіндемені тексеру.
- Strategy арқылы вакансияларды сұрыптау.
- Adapter арқылы сыртқы вакансия форматын бейімдеу.
- Visitor арқылы профиль/вакансия есебін шығару.
- Демонстрациялық деректер және іске қосу нұсқаулығы.

### MVP құрамына кірмейді
- Нақты веб-сайт және мобильді қосымша.
- Дерекқорға тұрақты сақтау.
- Нақты аккаунт/пароль авторизациясы.
- Онлайн төлем, чат және файл жүктеу.
- Нақты жұмыс сайттарымен интеграция.

## 7. Final нұсқасына жоспар

- Дерекқор қосу (PostgreSQL).
- REST API және веб-интерфейс.
- Авторизация және рөлдерге қолжетімділік.
- Түйіндемені PDF ретінде экспорттау.
- Вакансияға өтінім жіберу және өтінім мәртебесі.
- Автоматты тесттер және CI.

## 8. Паттерндерді қолдану картасы

| Паттерн | CareerBoost-тағы міндеті |
|---|---|
| Builder | Candidate профилін кезең-кезеңімен құру |
| Abstract Factory | Candidate/Recruiter компоненттер отбасын құру |
| Template Method | Түйіндемені тексеру алгоритмінің қадамдарын бекіту |
| Strategy | Вакансияларды әртүрлі тәсілмен сұрыптау |
| Adapter | Сыртқы вакансия дерегін ішкі модельге түрлендіру |
| Visitor | Профиль мен вакансияға есеп/талдау жасау |

## 9. Қабылдау және аяқталу шарттары

MVP дайын деп есептеледі, егер:
1. Жоба Java 17+ ортасында компиляцияланса.
2. Алты паттерннің әрқайсысы жұмыс істейтін мысалмен көрсетілсе.
3. 12 user story және қабылдау критерийлері құжатталса.
4. Іске қосу нұсқаулығы орындалса.
5. GitHub-та код, құжаттар және issue-жоспар жарияланса.
