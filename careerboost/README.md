# CareerBoost — Java Console Project

CareerBoost — жұмыс іздеушілерге арналған мансап платформасының оқу прототипі. Жоба Java 17+ және стандартты кітапханалармен жазылған.

## Қолданылған паттерндер

1. **Builder** — пайдаланушы профилін міндетті және қосымша өрістермен кезең-кезеңімен құру.
2. **Abstract Factory** — жұмыс іздеуші мен рекрутердің интерфейс компоненттерінің отбасын құру.
3. **Template Method** — түйіндемені тексеру процесінің ортақ қадамдарын бекіту.
4. **Strategy** — бос жұмыс орындарын әртүрлі тәсілмен сұрыптау/таңдау.
5. **Adapter** — сыртқы ескі форматтағы вакансия деректерін CareerBoost форматына бейімдеу.
6. **Visitor** — профиль мен вакансия деректеріне есеп/талдау жүргізу.

## Іске қосу (VS Code Terminal)

Java орнатылғанын тексеріңіз:

```bash
java -version
javac -version
```

Жоба бумасына өтіңіз:

```bash
cd careerboost
```

Компиляция және іске қосу:

```bash
javac -encoding UTF-8 -d out src/Main.java
java -cp out Main
```

Windows PowerShell және CMD терминалдарында да осы командалар орындалады.

## Демонстрация

Бағдарлама 6 паттернді бірінен кейін бірін көрсетеді. Әр бөлімде паттерннің мақсаты, қолданылған кластар және орындалу нәтижесі терминалға шығады.

## Құрылым

- `src/Main.java` — барлық паттерннің жұмыс істейтін демонстрациясы.
- `SRS.md` — функционалдық/функционалдық емес талаптар, 12 user story, қабылдау критерийлері, MVP шекарасы.
- `PROJECT_BOARD.md` — GitHub Projects тақтасына арналған жоспар.
- `MILESTONES.md` — MVP және Final кезеңдерінің міндеттері.
- `ISSUES.md` — GitHub-та ашылған тапсырмалар тізімі.

## Ескерту

Бұл — оқу мақсатындағы консольдік MVP. Нақты өндірістік нұсқада дерекқор, авторизация, веб-интерфейс және қауіпсіз төлем/жеке деректерді қорғау бөлек іске асырылады.
