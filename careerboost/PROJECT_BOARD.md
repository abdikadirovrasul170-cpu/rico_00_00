# GitHub Projects — CareerBoost тақтасы

Бұл файл GitHub Projects тақтасын құруға және issue-лерді бағандарға орналастыруға арналған жоспар.

## Тақта атауы
**CareerBoost Development Board**

## Ұсынылатын көрініс
Board view — Status бойынша топтау.

## Бағандар
1. **Backlog** — жоспарланған, әлі басталмаған жұмыс.
2. **Ready** — орындауға дайын.
3. **In Progress** — орындалып жатыр.
4. **Review** — тексеру/кодты қарау.
5. **Done** — аяқталған.

## Қосымша өрістер
- Status: Backlog / Ready / In Progress / Review / Done
- Phase: MVP / Final
- Priority: High / Medium / Low
- Pattern: Builder / Abstract Factory / Template Method / Strategy / Adapter / Visitor / Docs / QA

## Issue-лерді бөлу
- **MVP:** #1–#10 — консольдік негіз, алты паттерн және негізгі құжаттар.
- **Final:** #11–#15 — тестілеу, интеграция, кеңейту және финалдық құжаттама.

## Тақтаны GitHub-та ашу
1. Репозиторийге кіріңіз.
2. Projects → New project таңдаңыз.
3. Board шаблонын таңдаңыз.
4. Атын CareerBoost Development Board деп қойыңыз.
5. Жоғарыдағы бағандарды жасаңыз.
6. Add item арқылы осы репозиторийдегі issues-ті қосыңыз.
7. Phase және Priority өрістерін қосып, issue-лерді MVP/Final бойынша белгілеңіз.

> GitHub Projects тақтасын және GitHub milestone нысандарын осы ортадағы GitHub қосылымы арқылы тікелей құру мүмкіндігі берілмеген. Сондықтан тақта құрылымы мен кезеңдер жоспары құжатқа енгізілді; issue-лер репозиторийге жеке жарияланады.
