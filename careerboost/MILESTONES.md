# CareerBoost Milestones

## Milestone 1 — MVP
**Мақсат:** Java консольдік прототипін және алты паттерннің жұмысын көрсету.

Құрамына кіреді:
- [ ] SRS және 12 user story құжаты.
- [ ] Builder — профиль құру.
- [ ] Abstract Factory — рөлдерге арналған компоненттер.
- [ ] Template Method — түйіндемені тексеру.
- [ ] Strategy — вакансияларды сұрыптау.
- [ ] Adapter — сыртқы дерек форматын түрлендіру.
- [ ] Visitor — талдау есебі.
- [ ] Терминал мәзірі және README.

## Milestone 2 — Final
**Мақсат:** жобаны тексеру, құжаттау және кеңейтуге дайындау.

Құрамына кіреді:
- [ ] Барлық паттернге тест сценарийлері.
- [ ] Қате енгізулерді өңдеу.
- [ ] Архитектура мен UML құжаттамасы.
- [ ] PostgreSQL және REST API интеграциясының жобасы.
- [ ] Финалдық демонстрация және қорытынды есеп.

## Definition of Done
- Код компиляцияланады.
- Негізгі сценарийлер тексерілген.
- Құжаттама жаңартылған.
- GitHub issue жабылып, тақтадағы Status = Done қойылған.
