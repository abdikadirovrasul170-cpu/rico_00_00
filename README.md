# AEROLINK — Авиа логистика

VS Code-та ашуға арналған толық оқу жобасы. Сайт пен Java мысалы жеке орындалады; Java сайттың сервері емес.

## 1. Ең жылдам іске қосу

1. ZIP архивін толық ашыңыз.
2. VS Code → File → Open Folder → AEROLINK-Full папкасын таңдаңыз.
3. Сайт: index.html файлын браузермен ашыңыз.
4. Сайттағы «4 топ тәжірибесі» сілтемесін басып, барлық топты байқап көріңіз.

VS Code-та Extensions бөлімінен Live Server орнатсаңыз, index.html → оң жақ батырма → Open with Live Server арқылы ашуға болады. Сайтқа npm install қажет емес.

## 2. Java іске қосу

JDK 17 ұсынылады; кемінде JDK 11 қажет. VS Code-та Extension Pack for Java орнатуға болады. Терминалда тексеру: java -version.

Terminal → New Terminal ашып, жоба түбірінен орындаңыз:

```bash
java java/AirLogisticsDemo.java
```

Бұл төрт топты бірінен кейін бірін іске қосады. Жеке топ:

```bash
java java/AirLogisticsDemo.java 1
java java/AirLogisticsDemo.java 2
java java/AirLogisticsDemo.java 3
java java/AirLogisticsDemo.java 4
```

Немесе Terminal → Run Task → «Java: барлық 4 топ» таңдаңыз. VS Code Java кеңейтімімен AirLogisticsDemo.java ашып, Run басуға болады.

## 5. Қолдану

Басты бетте клиент атын, бағытты, салмақты және тарифті таңдаңыз. Тіркеген соң «Келесі кезең» арқылы мәртебені өзгертіңіз. Жүк нөмірі не клиент аты арқылы іздеңіз. Басты бет деректері браузерде сақталады.

Тәжірибе бетінде:

- 1-топ: салмақ пен тарифті өзгертіп, ортақ қоймадағы жүк санын қараңыз.
- 2-топ: стандартты/жедел жүк жасап, бөлімдерге Mediator хабарламасын бақылаңыз.
- 3-топ: ішкі/халықаралық рейс таңдаңыз; үйлесімді қаптама және құжат жасалады.
- 4-топ: құжат белгісін алып тастаңыз — тексеру тоқтайды. 1000 кг-нан жоғары салмақ та өтпейді. Қауіпті жүк белгісі қосылса, арнайы тексеру қажет. Барлық тексеру өткенде Command арқылы күй ауысады.

Тәжірибе журналы жадта сақталады, бетті жаңартқанда тазаланады.

## 6. Шектеулер

Бұл оқу демонстрациясы: нақты рейс, төлем, брондау, хат жіберу және ортақ серверлік база жоқ. Бағалар шартты: стандартты 1500 ₸/кг, жедел 2500 ₸/кг. Басты бетте сақтау браузер қолжетімділігіне байланысты. Салмақ 0.1–10000 кг; 4-топтағы оқу тексеруі 1000 кг лимитін қолданады.

Java бағдарламасы Java 17 ортада сәтті орындалды. JavaScript синтаксисі және төрт топтың негізгі логикасы тексерілді. Браузерде визуалды тексеру орындалмады.
