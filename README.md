# AEROLINK — Авиа логистика

Қазақша әуе жүктерін басқаруға арналған оқу жобасы. HTML, CSS, JavaScript және жеке Java консоль мысалы.

## Мүмкіндіктер

Жүк тіркеу, баға есептеу, іздеу, мәртебе сүзгісі, күй ауыстыру, клиент хабарламалары, көрсеткіштер, бес паттерннің түсіндірмесі мен Java үзінділері. Телефонға бейімделген. Деректер браузердің localStorage қоймасында сақталады.

Тарифтер мен бағыттар — оқу мысалы. Нақты брондау және электрондық хат жіберу жоқ. Әр браузердің деректері жеке, ортақ серверлік база жоқ.

## Сайтты іске қосу

Code → Download ZIP арқылы жүктеп, архивті ашыңыз. index.html файлын браузерде ашыңыз немесе VS Code Live Server қолданыңыз.

Python орнатылған болса:

~~~bash
git clone https://github.com/abdikadirovrasul170-cpu/rico_00_00.git
cd rico_00_00
python -m http.server 8000
~~~

Браузерде http://localhost:8000 ашыңыз. Қосымша пакеттер немесе құрастыру қажет емес.

## Java іске қосу

JDK орнатылған болуы керек:

~~~bash
cd java
javac -encoding UTF-8 Main.java
java Main
~~~

Онлайн компиляторда java/Main.java кодын Main.java ретінде орындауға болады. Java мысалы сайттың сервері емес.

## Тексеру

10 кг үшін стандартты тариф: 15 000 ₸; жедел тариф: 25 000 ₸. Жүкті тіркеп, «Келесі кезең» арқылы жеткізілген күйіне дейін жылжытыңыз. Соңғы күйде батырма өшеді. Іздеу және сүзгілеуді қолданыңыз. Бетті жаңартқанда, браузерде сақтау қолжетімді болса, деректер сақталады.

JavaScript синтаксисі, бес паттерн логикасы, салмақты тексеру және сақтау тексерілді. Браузердегі визуалды тексеру мен Java компиляциясы осы ортада орындалмады.
